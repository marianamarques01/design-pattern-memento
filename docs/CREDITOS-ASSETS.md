## Como o recorte foi feito

Os sheets de idle têm **128×256 px**. O layout foi conferido com inspeção dos pixels: 2 colunas × 4 linhas de frames de **64×64**. A ordem das linhas é `up`, `left`, `down`, `right`. O frame usado é `down` (índice 2, y=128), primeira coluna (x=0). O script reprodutível está em `scripts/preparar_assets.py`.

## Miniaturas

As miniaturas da personalização são recortes do alfa de cada peça, com 5 px de margem transparente. Elas não são desenhos novos: são a própria arte LPC exibida sem o corpo.
